Projects

Hybrid Network and Host-Based Defenses for Cybersecurity

Network Security · Host-Based Security

This research explores hybrid defense architectures that combine network-level visibility with host-based telemetry. The goal is to improve detection accuracy and response time against sophisticated multi-stage attacks, leveraging programmable networks (P4 and SmartNICs) and eBPF technology to offload and accelerate security functions.

Campus Cyberrange

Cyber Range · Hands-On Training

Building and operating a campus cyber range for hands-on training, research, and safe experimentation with network security and defense techniques.

AI Red Teaming

AI Security · Red Teaming

Studying adversarial attacks against generative AI systems and developing red-teaming methodologies to evaluate and improve their robustness.

OpenStack Security

Cloud Security · Infrastructure

Assessing and hardening the security of OpenStack-based private cloud infrastructure, including access control, network isolation, and threat detection.
